This data is obtained from https://github.com/ipta/mdc2?tab=readme-ov-file

We choose the "b" version of dataset 2 which is unevenly sampled and has all the usual noises included. The injections used to generate the data are included in the .json files. 

We have removed a "new.par" file which is included in the original repo - not sure what this is there for but it seems to be superfluous.
